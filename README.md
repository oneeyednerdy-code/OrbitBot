# Orbit v0.1.0-alpha.43

Orbit is the Nerdspace Labs Discord community control center: one modular bot/dashboard for community security, moderation, verification, roles, tickets, scheduling, automation, creator tools, social connections, and operations.

Alpha.43 keeps the cumulative Discord reliability, Scheduler, diagnostics, verification, and role-gated Twitch/YouTube alerts. It prevents late Tickets requests and action refreshes from replacing a different dashboard page.
