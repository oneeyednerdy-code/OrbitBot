# Orbit v0.1.0-alpha.40

Orbit is the Nerdspace Labs Discord community control center: one modular bot/dashboard for community security, moderation, verification, roles, tickets, scheduling, automation, creator tools, social connections, and operations.

Alpha.40 keeps the cumulative Discord reliability, Scheduler preview, and visible-version fixes. Diagnostics and Logs now recover cleanly when the verbose-error migration is missing and identify the exact deployment command required.
