# Orbit v0.1.0-alpha.56

Orbit is the Nerdspace Labs Discord community control center: one modular bot/dashboard for community security, moderation, verification, roles, tickets, scheduling, automation, creator tools, social connections, and operations.

Alpha.56 is the cumulative Orbit build. It adds a shared reliability control plane: Permission Doctor, configured-resource drift scanning, rate-limit visibility, Action Center history, supervised Gateway health, and event RSVP panels, while retaining the Community Engagement sample-bank dropdown.

Start with `START-HERE.md`, then read `ALPHA36-RECOVERY.md`. Guild authorization notes remain in `ALPHA35-SETUP.md`. Social-provider setup remains in `ALPHA34-SETUP.md`.
