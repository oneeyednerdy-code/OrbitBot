# Orbit v0.1.0-alpha.34

Orbit is the Nerdspace Labs Discord community control center: one modular bot/dashboard for community security, moderation, verification, roles, tickets, scheduling, automation, creator tools, social connections, and operations.

Alpha.34 adds real social account authorization paths for Threads and Mastodon, secure Bluesky app-password authorization, verbose sanitized error logging, visible Discord Scheduled Event failures, non-destructive role-panel deletion, and editable Applications/Appeals forms with up to 10 questions. It also removes the onboarding question asking what kind of Discord server is being configured.

Start with `START-HERE.md`, then read `ALPHA34-SETUP.md` for the new connection setup.
