# Orbit v0.1.0-alpha.30

This is the first **single cumulative roadmap deployment**. It folds the previous alpha.8–alpha.21 line and the alpha.22–alpha.30 operational features into one project.

Highlights: Shield Mode, Community Alerts, Creator Directory, community events with Discord Scheduled Events, Applications & Appeals, Community Health, Creator Safety Mode, and the Operations Center.

The release remains alpha software. Test moderation, permission-changing, Gateway, webhook and external-platform behavior in a non-production Discord server before enabling it in a large community.
