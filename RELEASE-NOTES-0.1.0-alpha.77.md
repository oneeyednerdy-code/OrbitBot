# Orbit v0.1.0-alpha.77 — Navigation and Sorting Cleanup

- Replaced the hardcoded sidebar with a registry-driven navigation model.
- Reorganized navigation into Community, Moderation, Automation, Creator, and System sections.
- Aligned the Overview module card order with the navigation model.
- Added Creator Safety Mode to the visible Moderation section for protection-enabled servers.
- Renamed Social to Social Publishing and Add More Features to Manage Features.
- Standardized server, channel, and role ordering across the dashboard.
- Added a size sort toggle for the server picker using Discord channel counts.
- Put upcoming scheduled social and Discord posts before historical items.
- Added a mobile sidebar scrim, Escape-to-close behavior, and accessible menu state.

No new D1 migration is required.
