# Orbit v0.1.0-alpha.79 — Cost-Aware Future Features

Alpha.79 extends the Orbit roadmap with budget-aware future planning.

## Added

- Twitter/X posting is listed under Social as a future feature.
- The roadmap explains that Twitter/X API costs are a project budget concern, not a reason to paywall the Orbit feature.
- Added future consideration entries for Facebook Page posting, cross-platform analytics, and expanded media retention.
- Added explicit language for provider review, API limits, storage, egress, and ongoing maintenance costs.

No new D1 migration is required.
